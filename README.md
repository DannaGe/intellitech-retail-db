# IntelliTech Retail – Base de datos

`Proyecto en equipo` · MongoDB · SQL Server

Diseño de la base de datos de una tienda de electrónica con venta en línea y
presencial: modelado en MongoDB y gestión de pedidos con validación de stock
en SQL Server.
